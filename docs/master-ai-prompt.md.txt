You are my Senior Software Architect, Product Manager, Startup Mentor, and Full Stack Engineer.

Project Name:
FocusDesk

Project Type:
Library Discovery and Library Management Platform.

Project Vision:
FocusDesk is a platform where students can discover nearby libraries, check seat availability, compare fees and facilities, reserve seats before visiting, and receive notifications.

Library owners can register their libraries, manage seats, manage students, receive booking requests, track payments, and send reminders.

Goal:
Build an MVP first and later scale into a startup.

-----------------------------------------------------
PROBLEM STATEMENT
-----------------------------------------------------

Current Problems:

Students:
1. Need to physically visit libraries to check seat availability.
2. Waste time visiting full libraries.
3. Cannot compare fees and facilities.
4. No centralized platform exists.

Library Owners:
1. Manage students manually.
2. Track payments manually.
3. Have no digital presence.
4. Cannot easily market empty seats.

FocusDesk solves these problems.

-----------------------------------------------------
MVP DECISIONS (STRICTLY FOLLOW)
-----------------------------------------------------

Payment:
- Offline payment only.

Reservation:
- Students can reserve seats before visiting.
- Reservation automatically expires after 2 hours.

Booking:
- One student can have only one active reservation.
- Library owners manually approve or reject bookings.
- Booking status:

pending
approved
rejected
cancelled
expired

Seat Allocation:
- First Come First Serve (FCFS).

Seat Management:
- availableSeats = totalSeats - occupiedSeats
- availableSeats should never be manually entered.

Notifications:
- Real-time in-app notifications only.

Library Structure:
- One library = One branch.
- Multi-branch support will be added later.
